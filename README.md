# DIVAi

Дежурный живёт на TimeBox Mini в обычное время. Режиссёр появляется, когда пора снимать. Для первого дубля в комплекте есть короткий немой клип с шаром и готовая реплика. Потом можно подставить свой ролик.

## Рабочая копия на Mac

В Терминале открой папку, где хранишь проекты, и выполни

```bash
git clone https://github.com/markoblogo/DIVAi.git
cd DIVAi
```

Эту же папку DIVAi можно открыть как проект в Codex. Чтобы получить опубликованные изменения, выполни в ней `git pull --ff-only`. Если раньше запускал версию из ZIP, скопируй в корень клона свой `director.json`, `observer.json` или прежний `character.json`, если он есть.

## Первый дубль

1. Открой Терминал в папке DIVAi. Если открыт повседневный пульт, нажми в его окне Q, чтобы освободить колонку.
2. Выбери TimeBox-mini-audio в настройках звука Mac как устройство вывода. Затем выполни `bash shoot.command`. В браузере откроется плеер с тестовым роликом. Терминал оставь открытым на время съёмки.
3. Нажми «Дубль с начала». Шар скатится со стола. На четвёртой секунде ролик встанет на паузу, Режиссёр посмотрит в камеру и скажет «Отлично. Главный герой ушёл из кадра». После реплики ролик продолжится.
4. Для своего дубля открой локальный видеофайл, найди момент, отметь его и впиши реплику. Запусти дубль с начала. Точка реакции отсчитывается по времени самого видео. Один дубль содержит одну реплику.
5. Чтобы закончить сеанс съёмки и освободить колонку, нажми Control+C в Терминале. Теперь можно запустить повседневный режим.

Для репетиции без колонки запусти `bash shoot.command --preview`. В этом режиме движения Режиссёра видны в браузере, а длительность реплики рассчитана приблизительно.

Для собственного материала лучше начать с MP4 с видео H.264, которое открывается в браузере на твоём Mac. Ролик, выбранный с диска, открывается локально. Его можно заранее положить на диск Work. Для первой сцены подойдёт момент, когда смысл действия понятен даже с выключенным звуком.

Озвучку делает macOS. Для реплики на русском программа попробует выбрать установленный русский голос. Можно явно указать имя голоса командой `bash shoot.command --voice "ИМЯ"`. Имена и языки доступных голосов покажет `say -v '?'`. Озвученные реплики записываются в подпапку `takes` в формате AIFF, откуда их можно взять в монтаж. Голос и звук видео по умолчанию используют текущий системный аудиовыход. У деморолика звуковой дорожки нет.

Если в кадре ноутбук стоит справа от колонки, запусти `bash shoot.command --side right`. Для левой стороны укажи `--side left`.

## Дежурный на каждый день

Запусти `bash start.command`. Первым на экране будет Дежурный. Оставь окно пульта открытым. Клавиши работают в латинской раскладке.

| Клавиша | Действие |
|---|---|
| H | Показать время или вернуться к лицу Дежурного |
| S | Перейти к ручной съёмке с Режиссёром |
| D | Вернуть Дежурного |
| G, C | Посмотреть на ноутбук или в камеру |
| B, T | Моргнуть или произнести реплику |
| M, P | Сменить сторону взгляда или цвет основы |
| Q | Завершить работу пульта |

Для ручной сцены со своей фразой можно сразу запустить `bash start.command --mode shoot --line "Вот это оставим."`. Для репетиции в Терминале используй `bash start.command --preview`.

## Твои рисунки

Открой `editor.html` двойным щелчком. Выбери Дежурного или Режиссёра и позу, затем рисуй по сетке 11 × 11 и нажми «Проиграть мимику». Чёрная кисть гасит пиксель. Сохрани файл для нужной роли рядом со `studio.py`. Для Дежурного используется `observer.json`, для Режиссёра `director.json`. Так у каждой роли останется собственный рисунок.

Сохранённый JSON можно снова открыть в редакторе. Собственные рисунки и аудиодубли из `takes/` остаются локальными.

## Проверка без колонки

```bash
python3 -m unittest discover -s tests
bash shoot.command --preview
```

Первая команда проверяет повседневный и съёмочный режимы, вторая открывает плеер для немой репетиции. Для проверки изображения на матрице и голоса через Bluetooth запусти `bash shoot.command` на Mac.

## Системные требования

Проект рассчитан на TimeBox Mini 11 × 11, Python 3.8+ и инструменты командной строки Xcode. Если первая версия уже работала на этом Mac, используй те же настройки. Для первой установки инструментов Apple служит `xcode-select --install`. При системном запросе разреши Bluetooth. Кадры уходят через Bluetooth, кабель можно оставить подключённым.

На колонку одновременно выводит кадры один пульт. Если подключение занято, заверши предыдущий сеанс или закрой другое приложение Divoom. Для переименованной колонки можно задать её Bluetooth-адрес в переменной `DIVOOM_TIMEBOX_ADDRESS`.

Модуль связи основан на [den-sv/div-box](https://github.com/den-sv/div-box). Версия исходников и лицензия находятся в папке vendor.
